# 小电视避雷针

一款面向哔哩哔哩网页端的浏览器插件：**众包标记低质量视频**（AI 低创 / 标题党 / 造谣），在你点开视频之前、刷推荐流的时候，用不打扰的方式提醒你——不挡画面、不暂停播放、随时可关。

> 所有提醒均来自社区用户的标记，仅供参考，不代表平台或本插件立场。

## 功能

- **播放页角标**：视频标题旁的小角标显示社区标记（如「⚠ AI低创 · 3」），点击展开标记理由、证据链接，可直接 👍/👎 投票；点 × 对本视频关闭。
- **推荐流角标**：首页 / 搜索 / 热门 / 播放页右侧相关视频的卡片上，对存在「已确认」标记的视频显示文字角标，悬浮查看详情。
- **标记提交**：播放页常驻「＋ 标记」按钮 → 选分类 → 从常用理由中选一条修改或自己写 → 提交。「造谣」分类必须附证据链接。
- **撤回与重提**：每人每视频每分类一次；已提交的标记可随时撤回，撤回后可重新提交。
- **离线可用**：服务器暂不可达时，提交自动保存在本地，恢复后每小时自动同步，不丢数据。

## 安装（Chrome / Edge）

当前为开发版，需从源码构建：

1. 安装 [Node.js](https://nodejs.org/)（建议 ≥ 20）
2. 下载本仓库，在仓库根目录执行：
   ```bash
   npm install
   npm run build
   ```
3. 打开 `chrome://extensions`，开启右上角「开发者模式」
4. 「加载已解压的扩展程序」→ 选择本项目的 `dist/` 目录
5. 打开任意 B 站页面即可使用

## 服务器

插件默认连接本地开发服务器（`http://127.0.0.1:8787`，启动方式见「开发」）。公共服务器上线后，在扩展的**选项页**填入正式地址即可。未连接服务器时插件自动进入本地模式：功能不受影响，你的标记提交仅自己可见。

## 隐私

- **匿名使用**：首次使用时本机随机生成一个私人 ID（类似密码，仅存本机、丢失不可找回），服务器只收到它的单向哈希，不收集任何 B 站账号信息。
- **不抓取第三方数据**：「查UP主成分」只是跳转到第三方网站（aicu.cc）的链接，是否访问由你决定，插件不抓取、不缓存其数据。
- **高敏分区隔离**：时政、社会等高敏内容分区不启用标记与提醒。
