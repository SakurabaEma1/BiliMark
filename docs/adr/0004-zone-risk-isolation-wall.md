# 0004 — 分区作为风险隔离墙，v1 不做分社区聚合

高敏分区（鉴政区等）在 v1 直接不启用：不接受标记提交、不展示提醒。其余分区进入同一套全局聚合，不按分区分别计算；分区信息记入标记元数据，为二期「分社区对比参考」预留数据基础。

理由：与 SponsorBlock 不同（广告片段客观存在，全站通用），本项目的分类判定主观度更高，风险随内容分区剧烈变化——鉴政区的「造谣」标记等于运营者替用户做政治定论，是不可承受之重。分区隔离墙是简单可执行的风险边界；分社区独立聚合则导致数据碎片化、各区冷启动难度翻倍、跨区协同被切断，且给串子留下「攻占单区系数」的靶子。

## Consequences

- 一旦某分区曾被启用并收集过标记，事后收紧边界会面对已存数据的处置问题——宁可 v1 从紧，逐步开放。
