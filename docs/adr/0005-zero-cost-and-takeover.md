# 0005 — 零边际成本与可接管性约束

运营者无稳定收入，项目为业余兴起。两条硬约束进架构：

1. **零边际成本**：读接口全部可缓存、批量设计；静态订阅列表走 GitHub 免费通道；不引入按量付费依赖。
2. **可接管性**：插件与服务端全开源（GPL）；数据格式文档化；全量 dump 定期公开发布（SponsorBlock database.zip 先例）；插件端对服务器不可达做优雅降级——本地缓存 + 最近订阅列表 + UI 明示数据时效。

理由：社区数据产品的真实死法不是「做不下去」，而是「运营者停付即全站停摆」。把存续能力做进架构后金额不再是风险：极限档（CF 免费档 + 特价域名）≈ ¥0-30/年，稳妥档（年付促销海外 VPS）≤ ¥200/年。

## Considered Options

- 依赖单一自建服务器、无接管路径——被否：运营者一旦停付，社区数据与用户插件同时死亡。
