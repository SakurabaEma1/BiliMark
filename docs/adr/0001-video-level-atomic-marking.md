# 0001 — 标记原子单元为视频级，UP主警示仅作派生

社区标注的原子单元是「单个视频（BV）的整体低质判定」，而非 SponsorBlock 的「视频内时间片段」，也非独立众包的「UP主级判定」。UP 主级警示由同一 UP 名下的视频标记聚合派生而来，用户不可直接提交 UP 级判定；全局共享的 UP 黑名单推迟到二期。

理由：单个视频是否 AI 低创/造谣是可验证的事实判断，投票争议与名誉权风险都低；「这个 UP 是串子」是观点判断，是恶意用户最想污染、法律风险最高的对象。事实层共享、观点层本地，是风险与冷启动难度最低的分层。

## Considered Options

- **UP主级为原子**（贴合原始动机「斩断少数带节奏的源头」）——被否：把最难验证、最易被攻击、法律风险最高的对象放在系统中心。
- **两者并列、各自独立**——被否：v1 需同时设计两套治理规则，复杂度与冷启动难度翻倍。
