# 0002 — 去身份化的分层信任，不绑定 B 站账号

提交标记与投票不要求任何实名/平台身份（匿名私人 ID，SponsorBlock 同模式），对抗 Sybil 的锚点放在分层机制上：新账号更高确认阈值 → 声誉随被确认数晋升 → 高声誉获 VIP 权限（锁定、快速通道、仲裁）→ 影子封禁兜底 → 服务端 IP/行为风控。不依赖 B 站官方接口做身份验证。

理由：绑定 B 站账号需依赖非官方 passport 接口，有 ToS 与风控封口风险，且把贡献者与实名身份绑死会抬高参与门槛、拖垮冷启动；邀请制则牺牲增长，而标记系统的价值与覆盖面成正比。扫码验证可作为二期可选的「加权」而非门槛。

## Considered Options

- **强制绑定 B 站身份**——被否：接口非官方、ToS 风险、实名绑死、冷启动难。
- **邀请制信任链**——被否：增长太慢，社区规模是标记系统的命门。
