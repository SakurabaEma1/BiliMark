# 0007 — 治理信任根：行为成本型 + 种子人工授信

治理体系（新手期、声誉、影子封禁、VIP）的信任根信号是**行为成本**：信任来自历史贡献的积累（被确认的提交、净票），匿名私人 ID 重新生成等于从零开始——刷号者的代价是重新积累的劳动与时间，而非身份成本。声誉数据全部可从现有 submissions/votes 表按 public_id 回算，无需 schema 变更。种子期由运营者人工授予 VIP 作为信任加速层（ADR-0002 已有 VIP 概念），弥补纯行为成本在早期没有晋升梯度的缺陷。

## Considered Options

- **平台行为指纹**（IP 信誉/行为特征）——被否：工程复杂、NAT/校园网误伤率高，与去身份化决策张力最大。
- **纯人工授信**——被否：无自增长梯度，普通贡献者看不到晋升路径；保留为加速层而非唯一信任源。
- **完全暂缓**——被否：规则口径现在定型零成本，拖延会把口径决策拖进有数据的返工期。

## Consequences

- 执行后置：v0.3 用户≈0，强制逻辑随用户量启用；服务器留常量钩子（新手期倍率、声誉权重）。
- 影子封禁的触发判据（自动启发式 vs 人工）待后续 grill 定型。
