# 可行性分析

日期：2026-09-27。术语定义见 [CONTEXT.md](../CONTEXT.md)，架构决策见 [docs/adr/](./adr/)。

## 一句话定义

众包标记低质量 B 站视频（AI低创/标题党/造谣），在播放前与推荐流中分级提醒用户；事实类先行、观点类暂缓、高敏分区隔离。

## 与 SponsorBlock 的根本差异

| | BilibiliSponsorBlock | 本项目 |
|---|---|---|
| 标注对象 | 好视频里的坏片段（时间轴 [start,end]） | 坏视频整体（实体级 BV） |
| 判断性质 | 客观存在（广告就是广告，全站通用） | 半主观（随分区、立场剧烈变化） |
| 干预方式 | 自动跳过 | 提醒为主；过滤仅限用户自己的本地黑名单 |
| 用户体系 | 私人 ID 匿名 + 投票/声誉/VIP | 同左，另加新手期、影子封禁、分区隔离墙 |

## v1 决策清单

1. **标记原子 = 视频（BV）**。UP主警示为派生聚合，不可直接提交「UP主是惯犯」；用户本地黑名单先行。[ADR-0001]
2. **分类 v1 三类**：AI低创（B站官方 AI 生成标注作预填锚点）、标题党、造谣（提交强制附证据链接）。引战/带节奏等观点类延后。
3. **全触点 + 非阻断干预**（遵循非阻断原则）：播放页为标题行内联的分类角标（SB 分类角标同位，零推挤、点击展开理由下拉浮层） / 推荐流角标（视频卡片右下角文字形标签，悬浮展开详情，覆盖首页/搜索/热门与播放页右侧「相关视频」） / 本地黑名单直接隐藏；强度按分类可配置（角标/关闭）。信息主层是推荐流角标，播放页分类角标仅为直链与连播场景兜底。
4. **聚合 = （视频，分类）状态机 + 原始数字**：待确认 → 已确认（净赞成≥确认阈值）→ 有争议 → 驳回。UP主警示 = 同分类已确认视频数达门槛，展示「5个视频被确认AI低创」式原始计数，不做连续分数。
5. **治理 = 分层信任、去身份化**：新手期高阈值 → 声誉晋升 → VIP（锁定/快速通道/仲裁）→ 影子封禁 → 服务端 IP/行为风控。不绑定 B 站身份。[ADR-0002]
6. **查成分 = v1 深链外联**（aicu.cc 外链按钮）+ 本地备注自建；不抓取、不缓存第三方数据。
7. **形态 = MV3 插件 + 自研轻量 API（海外 VPS 免备案）+ 已确认标记订阅列表导出**。[ADR-0003]
8. **合规 = 全套内置**：中性措辞（社区提示）、被标记 UP 的申诉通道、隐私政策 + IP 哈希化、商店文案包装、通知-处置流程。
9. **冷启动 = AI低创垂直引爆**：装即用（存量标记立即生效）+ 候选池半自动发现（B站AI标注筛候选、志愿者认领复核）+ 创始团队种子标记 + SB/Bilibili-Evolved/BiliScope 社区借力与订阅列表互推。
10. **分区 = 风险隔离墙**：鉴政区等高敏分区不启用；全局聚合；分区入元数据为二期分社区对比预留。[ADR-0004]

## 可行性判定

- **技术：✅ 可行**。三个先例充分验证了关键环节——SB（插件注入 + 中心服务器 + 治理体系全套跑通 6k stars）、BiliScope（悬浮卡注入 + B站 API 只读使用）、Bilibili-Evolved/BewlyBewly（feed 过滤）。本项目数据模型比 SB 还简单（无时间轴、无 cid 纠缠）。
- **成本：✅ 可行**。已按「运营者无稳定收入」的约束重新核算并写入 ADR-0005（零边际成本 + 可接管性），详见下文「成本与存续」。
- **法律：⚠️ 有条件可行**。隔离墙/申诉通道/中性措辞是**必要条件**而非可选项；最大单点风险（政治内容的「造谣」标记）已被分区隔离墙化解。「标题党」「AI低创」的争议度与名誉权暴露都显著更低。
- **运营：⚠️ 最大不确定项**。冷启动的标记供给是生死线；「消费者零门槛 + 单类目垂直 + 生态借力」是已知最稳路径，成败取决于执行。

## 风险 Top3

1. **冷启动供给不足** → 装了没数据 → 流失。缓解：装即用、候选池降低发现成本、订阅列表让非插件用户先受益。
2. **串子污染**（抢注、刷票、恶意反对、攻占新类目）。缓解：状态机边界 + 新手期 + 声誉 + 影子封禁 + IP 风控；不做连续分数（没有可攻的靶心）。
3. **平台与法律**（商店下架、UP 投诉、B站接口变动）。缓解：文案包装为「社区内容提示」、申诉通道、通知-处置流程、插件只读公开数据不碰登录态写接口。

## 成本与存续

| 项目 | 金额 | 说明 |
|---|---|---|
| 域名 | ¥10-60/年 | .top 等特价域名，续费略高 |
| API 托管（稳妥档） | ¥70-150/年 | 海外年付促销 VPS（1核1G 足够），免备案 |
| API 托管（极限档） | ¥0 | Cloudflare Workers + D1 免费档（约 10 万请求/天） |
| 静态列表托管 | ¥0 | GitHub Pages / raw |
| 数据备份 | ¥0 | 定时 dump 推送到 GitHub 仓库 |
| **合计** | **¥10-200/年** | 稳妥档 ≈ 每月几元，极限档趋近于零 |

规模转折点：免费档 10 万请求/天在「批量接口 + 全链路缓存」设计下对应很高的日活量级，社区插件短期达不到；真达到时社区已成形，捐赠模式（SB 先例）才变得现实。

选型时点：开发阶段零成本（本地跑），上线时实测国内可达性后在促销 VPS 与 CF 免费档之间二选一；预算上限 ≤¥200/年（含域名），选型不阻塞开发。

存续设计（ADR-0005）：项目的真实死法是「运营者停付即全站停摆」，因此 ① 读接口全可缓存、静态列表双通道；② 全开源 + 数据格式文档化 + 定期全量发布（CONTEXT.md「全量发布」），任何第三方可 fork 重启；③ 插件端优雅降级——服务器不可达时读本地缓存与最近列表，UI 明示时效，不报错不摆烂。

## 二期路线图

- 观点类类目（引战/带节奏/串子判定）——需先有更重的治理与仲裁积累
- 共享 UP 黑名单（原始核心诉求，需独立治理设计）
- 分社区对比参考（v1 的分区元数据是数据基础）
- B 站扫码验证作为可选「加权」而非门槛
- 与 BiliScope 的备注/标签导入导出互认

## 实现期待定项（不属于本轮对齐范围）

- 具体阈值（确认票数、UP警示门槛、新手期倍率）——数据调优
- UP 申诉的身份验证流程（邮箱 + 人工/VIP 仲裁）
- 视频被删除/改标题后标记的存档策略；可借鉴 SB 的 videoDuration 防换源与 BVID 哈希前缀隐私查询协议
- 插件 UI 细节与技术栈（沿 SB 路线：TypeScript + webpack 基本确定）
